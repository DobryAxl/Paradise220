Geoip admin panel
/datum/ui_module/admin/geoip

TGUI report of every connected client's ping and GeoIP data. Read-only; lazily triggers a GeoIP refresh on any row whose status is not "updated".

Can be opened in two modes:

  • Full list — every connected client. Used by the View Geoip admin verb.
  • Single-client — one ckey only. Used by the GeoIP link on the player panel.

Vars

target_filtersPer-viewer ckey filters. Keyed by viewer ckey, value is the target ckey to pin the view to.

Procs

ui_interactOpens (or re-focuses) the panel for user. Passing target_ckey restricts the view to that single client and renames the window accordingly; passing null shows every connected client.
